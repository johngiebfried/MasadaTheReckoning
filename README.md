# Masada: The Reckoning

Classroom companion pages for *Masada: The Reckoning*, a Reacting to the Past microgame by John Giebfried.

- **[The Road to Masada](https://johngiebfried.github.io/MasadaTheReckoning/)** (`index.html`): read before play. How Josephus came to write the only account of the war, and how the war reached Masada. About ten minutes.
- **[After Masada](https://johngiebfried.github.io/MasadaTheReckoning/after.html)** (`after.html`): read after play. How the story was remembered, from Josephus to the rock today. About five minutes. It discusses material the game holds back until the debrief, so do not assign it before the session.

Both pages are self-contained HTML. Open them in any browser; no build step.
